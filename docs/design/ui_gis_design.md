# AI-EMS v5.1 GIS 시각화 + SLD + UI 설계

## 1. 개요

### 1.1 기본 철학
World Monitor 스타일 다크 테마를 기반으로 한 고급 에너지 관리 시스템(EMS) 시각화. NL(Natural Language) Navigation, HITL(Human-in-the-Loop) 승인 체계, AI 인사이트와 직접 연동하는 실시간 GIS 및 단선도(SLD) 렌더링.

### 1.2 v5.1 범위 (축소 버전)
**구현 대상:**
- L1~L2 (2D GIS): 국가급/권역급 송전망 시각화
- L4 (변전소 단선도): 모선·차단기·변압기·선로인입 상세 도시

**설계만 유지:**
- 2.5D/3D 틸트 뷰
- L3 (광역/도시 단선도)
- L5 (베이 단위 상세도)

### 1.3 핵심 기술 스택
- **지도 렌더링**: MapLibre GL JS (Vector Tiles)
- **단선도 렌더링**: D3.js (SVG)
- **UI 프레임워크**: Streamlit (Python)
- **스타일 정의**: SLD(Styled Layer Definition)
- **라우팅**: Screen Registry 기반 동적 네비게이션

## 2. 시맨틱 줌 5단계

### 2.1 Level 1: 전국 광역도 (v5.1 Phase 3)
**줌 레벨**: 4~5
**표시 대상**:
- 345kV 주간선로만 표시
- 대규모 발전소(원전, 수력, 화력 >1000MW)
- 100개 이상의 Key Substation(대규모 변전소)
- 광역권역 경계선 (강조 표시 가능)

**시각 요소**:
- 송전선: 3px 굵기, 전압 색상 (345kV = 진한 청색)
- 발전소: 육각형 아이콘 (종류별 색상 구분)
- 변전소: 작은 원 아이콘 (주요 변전소만)
- 실시간 오버레이: 계획정지 구간 점선 표시

**상호작용**:
- 발전소/변전소 클릭 → L2로 자동 확대
- 선로 클릭 → 선로 속성 팝업
- 우측 패널에 설비 기본정보 표시

### 2.2 Level 2: 권역 상세도 (v5.1 Phase 3)
**�음 레벨**: 6~8
**표시 대상**:
- 345kV + 154kV 모든 선로
- 모든 변전소 (대·중·소 포함)
- 송전선로 구간별 전압 표시
- 연계선(타 권역 연결)

**시각 요소**:
- 345kV: 진한 청색 (#1E88E5)
- 154kV: 밝은 청색 (#42A5F5)
- 66kV: 녹색 (#66BB6A)
- 변전소: 크기별 계층화 아이콘
- 실시간 전압 색상: 정상(녹색) → 경계(황색) → 위반(적색)

**상호작용**:
- 변전소 클릭 → L4(단선도) 진입
- 우측 채팅에서 변전소명 발화 → 자동 확대+L4 진입
- 선로 드래그 → 다중선택 가능

### 2.3 Level 3: 광역/도시 단선도 (설계만 유지)
**향후 확장 계획**:
- 22kV 배전망 포함
- 도시 지역 상세 계통도
- 고객 연결 트리 표시

### 2.4 Level 4: 변전소 단선도 (v5.1 Phase 3)
**줌 레벨**: 9+
**표시 대상**:
- 모선 (BUS): 수평 직선으로 표시
- 차단기 (CB): 사각형 심볼 (ON=녹색, OFF=적색)
- 변압기 (TR): 원형 심볼 (용량 텍스트 포함)
- 선로인입 (LINE): 화살표 심볼 (방향 표시)
- 접지 저항기: T자 심볼

**실시간 오버레이**:
- 전압: 숫자 + 색상 (145kV 예상치 표시)
- 조류: 화살표 + 애니메이션 흐름 방향
- 부하율: 선 굵기 변동 (0~100%)
- 온도: 색상 그라데이션 (냉각장치)

**상호작용**:
- 차단기 ON/OFF 가능 (HITL 승인 팝업)
- 변압기 부하전환 (탭 조정)
- 우측 채팅: "154kV 모선 전압" → 하이라이트

### 2.5 Level 5: 베이 단위 상세도 (설계만 유지)
**향후 확장**:
- CT/PT 상세 위치
- 계전기 회로도
- 광섬유 OPGW 위치

## 3. 뷰 모드 (v5.1 범위)

### 3.1 2D GIS 모드 (구현, v5.1)
**기본 뷰**:
- MapLibre GL JS 기반 벡터 타일 렌더링
- 정사영(Orthographic) 투영
- 마우스 스크롤 줌, 드래그 이동
- 다중 레이어 토글 가능

**성능 최적화**:
- Cluster 기반 변전소 그룹화 (z8 이하)
- 선로 단순화 (Douglas-Peucker, ε=50m)
- 타일 캐싱 (IndexedDB, 1GB 제한)

### 3.2 2D SLD 모드 (구현, v5.1)
**D3.js 기반 SVG 렌더링**:
- 선형 레이아웃 (수평/수직 정렬)
- 심볼 라이브러리 (전기 표준 심볼)
- 선로 경로 자동 라우팅 (A* 알고리즘)

**대화형 기능**:
- 노드(모선, 차단기) 드래그 이동
- 선로 경로 수동 조정
- 우클릭 컨텍스트 메뉴 (속성 보기, 제어)

### 3.3 2.5D 틸트 뷰 (설계, ChatGrid 스타일)
**향후 개발**:
- Mapbox GL 3D 지형 +45도 회전
- 변전소 3D 박스로 표현
- 송전선로 3D 곡선 렌더링
- 마우스/터치 제스처 조작

### 3.4 3D 몰입형 뷰 (설계, Three.js)
**향후 개발**:
- Three.js 기반 완전 3D 환경
- 실시간 조명 (태양 위치 기반)
- 뷰포트 내 드론 시야각 선택 가능
- VR 헤드셋 지원 (WebXR)

## 4. 6개 맵 레이어 (z-index 순)

### 4.1 Layer 0: 기본 지도 (base)
**구성**:
- 지형 배경 (다크 테마 회색 #1a1a2e)
- 도로망 (희미한 회색선)
- 행정경계 (도/시/군 경계)
- 수계 (강, 호수 - 다크 청색)
- 지명 (한글 텍스트, 흰색 #f0f0f0)

**소스**: PMTiles (폐쇄망 대비 로컬 캐시)

### 4.2 Layer 1: 송전망 토폴로지 (grid_topo)
**구성**:
- 송전선로 (345/154/66kV 구분 색상)
- 변전소 아이콘 (크기: 고압/중압/저압)
- 발전소 아이콘 (종류별 색상)
- 주요 시설 레이블

**필터링**:
```
// 줌 레벨 별 표시 조건
zoom >= 4: 345kV only
zoom >= 6: 345kV + 154kV
zoom >= 8: all voltages
zoom >= 10: include 22kV
```

### 4.3 Layer 2: 실시간 SCADA (realtime)
**구성**:
- 선로 색상 (전압 정상/경계/위반)
- 조류 방향 화살표 (애니메이션)
- 변전소 실시간 상태 (전압/주파수 텍스트)
- 부하율 표시 (선 굵기 변동)

**갱신 주기**: 1~5초 (WebSocket 실시간 수신)

**색상 테이블**:
| 구간 | 색상 | RGB |
|------|------|-----|
| 정상 | 녹색 | #39FF14 |
| 경계 | 황색 | #FFB347 |
| 위반 | 적색 | #FF3B3B |
| 정지 | 회색 | #808080 |

### 4.4 Layer 3: 활성 알람 (alarm)
**구성**:
- 알람 마커 (점멍 애니메이션 + 심각도 색상)
- 알람 개수 뱃지 (우측 상단)
- 알람 상세 팝업 (호버)

**심각도**:
| 레벨 | 색상 | 점멍 속도 |
|------|------|---------|
| CRITICAL | #FF1744 | 1초 |
| HIGH | #FFB74D | 2초 |
| MEDIUM | #42A5F5 | 3초 |
| LOW | #9E9E9E | 4초 |

### 4.5 Layer 4: 기상 정보 (weather) - Phase 4
**구성**:
- 레이더 강우 정보 (컬러맵)
- 바람장(벡터 화살표)
- 낙뢰 감지 포인트
- 구름 위성 이미지

**데이터 소스**: Open-Meteo 기상 API (폐쇄망 시 사전 캐시)

### 4.6 Layer 5: 비교 분석 오버레이 (study) - 향후
**구성**:
- Study 케이스 결과 오버레이
- Base Case vs Study Case 차이 강조
- 색상 분화 (변동 없음=투명, 증가=주황, 감소=파랑)

## 6. D3.js 변전소 SLD 렌더링

### 6.1 전기 심볼 라이브러리

#### 6.1.1 모선 (Bus)
**표현**: 수평 직선
- 선 길이: 변전소 규모별 (소규모: 200px, 중규모: 400px, 대규모: 600px)
- 색상: 흰색 #f0f0f0 (전압에 따라 테두리 색상)
- 레이블: "345kV-A" (좌측 정렬)

```
345kV-A ────────────────────────
        ↑    ↑    ↑   ↑   ↑
       CB1  CB2  CB3 CB4 CB5
```

#### 6.1.2 차단기 (Circuit Breaker, CB)
**표현**: 사각형 심볼
- 기본: 30x30px 사각형
- 상태:
  - ON (투입): 녹색 #39FF14 (내부 채움) + 흰 테두리
  - OFF (개방): 적색 #FF3B3B + 회색 테두리
  - FAILED: 황색 #FFB347 + 깜빡임

```
CB ON:            CB OFF:           CB FAILED:
┌─────┐          ┌─────┐           ┌─────┐
│▓▓▓▓▓│          │     │           │░░░░░│ (깜빡임)
└─────┘          └─────┘           └─────┘
(녹색 채움)      (비어있음)         (황색 패턴)
```

#### 6.1.3 변압기 (Transformer, TR)
**표현**: 원형 심볼 또는 이중 원
- 기본: 반지름 40px 원
- 2권선: 원 2개 겹침 (1차/2차 구분)
- 3권선: 원 3개 배열
- 색상: 회색 #A0A0A0
- 내부 텍스트: 용량 "100MVA"

```
    1차         2차
    ┌─┐        ┌─┐
    │ │────────│ │  100MVA
    └─┘        └─┘
   345kV      154kV
```

#### 6.1.4 선로인입 (Feeder)
**표현**: 화살표 심볼
- 기본: 삼각형 (►) + 선로 경로
- 방향: 조류 방향 따라 방향 설정
- 색상: 전압 색상 상속 (345kV = 청색, 154kV = 연청색)

```
◄─── 송전선로  (인입 방향)
     ┌─────────────────┐
     │   변전소        │
     └─────────────────┘
     ────► 배전선로 (인출 방향)
```

#### 6.1.5 접지 저항기 (Ground Resistance)
**표현**: T자 또는 접지 기호
```
    ‖
    ══
   ═╪═
    ║
   ┌┴┐
   └─┘  (접지 기호)
```

#### 6.1.6 커패시터뱅크 (Capacitor Bank)
**표현**: 평행선 2개 (condensator 기호)
```
  ───
  ───
```

### 6.2 레이아웃 알고리즘

#### 6.2.1 자동 레이아웃 (D3 Hierarchy)
**선형 배치**:
1. 모선을 수평 기준선으로 배치
2. 각 모선 아래 차단기 배열 (10px 간격)
3. 차단기 아래 주요 설비 (변압기, 선로인입) 배열

```
       Top Busbar (345kV-A)
       ├─ CB1 ─┬─ TR1 (345/154)
       ├─ CB2 ─┬─ TR2 (345/154)
       │       └─ LINE (상주~목포)
       └─ CB3 ─┬─ TR3 (345/154)

       Middle Busbar (345kV-B)
       └─ CB4 ─┬─ 선로인입 (문경선)
```

#### 6.2.2 경로 라우팅 (A* 알고리즘)
**선로 연결 경로 자동 결정**:
- 노드 간 최단경로 계산
- 교차점 회피 (우측 우선)
- 각도 최소화 (90도 또는 45도)

```
사용자 정의 가능한 루트:
CB1 ─┬── TR1 (수평→하강→우측)
     └── LINE (수평→우측→하강)
```

### 6.3 실시간 데이터 오버레이

#### 6.3.1 전압 (Voltage)
**표현**: 숫자 + 색상 배경
- 위치: 모선 좌측 또는 상단
- 형식: "345.2 kV" (소수점 1자리)
- 색상: 정상(녹색) / 경계(황색) / 위반(적색)

```
345kV-A
  ┌─────────────────────────┐
  │ 345.2 kV ✓              │ (녹색 배경)
  ├─────────────────────────┤
  │  CB1 ◎ CB2 ◎ CB3 ◎    │
  └─────────────────────────┘
```

#### 6.3.2 조류 (Power Flow)
**표현**: 애니메이션 화살표 + 숫자
- 위치: 선로 중심
- 크기: 조류 크기에 따라 동적 조정
- 색상: 방향 확인용 (순방향=녹색, 역방향=주황)
- 애니메이션: 1초 주기 흐르는 효과

```
     420 MW  (숫자)
CB1 ─→ ━━ ━━ ━━ ─→ TR1  (애니메이션 화살표)
     (정방향: 녹색)

CB2 ← ━━ ━━ ━━ ← 변압기  (역방향: 주황색)
    -80 MW
```

#### 6.3.3 부하율 (Load Rate)
**표현**: 선 굵기 + 백분율 텍스트
- 기본: 2px
- 범위: 0% (1px) ~ 100% (4px) ~ 120% (6px 적색)
- 색상: 정상(녹색) / 주의(황색) / 초과(적색)

```
  80% [CB1] ─── (굵기 3px, 녹색)
 120% [CB2] ═══ (굵기 6px, 적색)
```

#### 6.3.4 온도 (Temperature, 냉각장치)
**표현**: 색상 그라데이션 + 숫자
- 위치: 변압기 아래
- 색상: 청색(30°C) → 녹색(50°C) → 황색(70°C) → 적색(90°C)

```
변압기 심볼
   ┌─┐
   │ │  냉각장치
   └─┘
   ▓▓▓▓  (색상: 70°C 황색)
   [71°C]
```

## 7. SCADA 실시간 오버레이

### 7.1 전압 색상 시스템

**정의**:
- **정상 (Green)**: 정격 ±5%
  - 345kV: 327.75 ~ 362.25 kV
  - 154kV: 146.3 ~ 161.7 kV
  - 색상: #39FF14

- **경계 (Yellow)**: 정격 ±10% 또는 ±5%~±10%
  - 345kV: 310.5 ~ 327.75, 362.25 ~ 379.5 kV
  - 154kV: 138.6 ~ 146.3, 161.7 ~ 169.4 kV
  - 색상: #FFB347

- **위반 (Red)**: 정격 >±10%
  - 345kV: <310.5, >379.5 kV
  - 154kV: <138.6, >169.4 kV
  - 색상: #FF3B3B

**시각화**:
- 선로: 색상 변환 (실시간 1~5초 주기)
- 변전소 아이콘: 테두리 색상 (내부 채움은 회색 유지)
- 모선 레이블: 텍스트 색상 변환

### 7.2 조류 방향 애니메이션

**구현**:
- 선로 상의 "점" 또는 "화살표" 애니메이션
- 방향: 순방향(A→B) 또는 역방향(B→A)
- 속도: 조류 크기에 비례 (0.5초 ~ 2초 주기)

```
정상 조류 (순방향):
CB1 ─→ ━━ ━━ ━━ ─→ TR1
      ↓↓↓↓↓↓↓↓↓  (1초 주기 점 이동)

역방향 조류:
CB2 ← ━━ ━━ ━━ ← 변압기
      ↑↑↑↑↑↑↑↑↑  (0.5초 주기)
```

**색상**:
- 순방향: 녹색 (#39FF14)
- 역방향: 주황색 (#FF9800) 또는 적색 (역류 주의)
- 정지: 회색 (#808080)

### 7.3 알람 마커

**시각적 요소**:
- 깜빡이는 원형 마커 (중심 아이콘 + 확장 원)
- 심각도별 색상:
  | 심각도 | 색상 | 깜빡임 | 우선순위 |
  |--------|------|--------|---------|
  | CRITICAL | #FF1744 (적색) | 1초 | 즉시 처리 |
  | HIGH | #FF9800 (주황) | 1.5초 | 우선 |
  | MEDIUM | #2196F3 (청색) | 2초 | 검토 |
  | LOW | #9E9E9E (회색) | 3초 | 기록 |

**알람 유형 아이콘**:
- 🔴 전압: V (전압 이상)
- ⚡ 조류: I (과전류)
- 🌡 온도: T (온도 초과)
- ⚠ 차단기: ! (차단기 이상)
- 📡 통신: ≈ (통신 단절)

**마커 동작**:
```
깜빡임 애니메이션:
t=0s:   ●━━━━━━  (반지름 10px)
t=0.2s: ○━━━━━━  (반지름 20px)
t=0.4s: ○━━━━━━  (반지름 30px)
t=0.6s: (사라짐)
t=0.8s: ●━━━━━━  (다시 시작)
```

### 7.4 HITL 승인 플로우

**트리거**:
- 사용자 또는 자동화 알고리즘이 제어 명령 요청
- 차단기 ON/OFF, 변압기 탭 조정 등

**팝업 표시**:
1. 명령 내용 (예: "여의도 변전소 CB-1 OFF")
2. Evidence Chain (인사이트 기반 근거)
3. 영향 범위 (차단 시 단전 가능 부하)
4. 카운트다운 타이머 (기본 30초)
5. 승인/거부 버튼
